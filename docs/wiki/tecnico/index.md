# Technical

The project's own code and content: scripts in `Assets/Scripts/`, scenes, prefabs, data assets. Unity and plugin behaviour is in their official docs, not here: [Odin Inspector](https://odininspector.com/documentation) (inspector attributes, `OdinEditorWindow`; no official MCP server or `llms.txt` as of 2026-10-19), DOTween, UniTask, TextMeshPro. Back to the [wiki index](../index.md).

- [Shared scripts](./shared.md): `Assets/Scripts/Shared/`: `CardData`, `CardDatabase`, `CardDataInGame`, `CardDisplay3D`, the card generator and `WindowsBuilder` (editor menus), `GameManager`, `SceneLoader` (Menu and Back buttons)
- [Table scripts](./table.md): `Assets/Scripts/Shared/Table/`, shared by the Panchina, Tribuna and Index40 scenes: `TableState` (logical table state and path rule: duplicates stacked, holes; bench that fills holes face down), `TableDeckManager` (deals a deck preset with a seed, bench or discard beyond 40, game log, reset), `OptionsPanel` (preset of the next game from the preset library, animation speed), controller (ignores clicks over the UI), animations, `CardSlot`, `CardSlotContainer`
- [Deck scripts](./deck.md): `Assets/Scripts/Shared/Deck/`: `DeckRules`, `ExcessCards` (panchina, tribuna, index>40), `CardPick` (removed and duplicated cards at random or the first ones), `DeckPreset` (4 standard presets: 32, 45, 60, 71 non-king cards, plus custom ones), `DeckPresetLibrary` (presets shared by options and simulation), `DeckBuilder` (seeded deal: 40 slots with holes at the end, or index>40 up to 80 slots), `DeckDeal`, the index rule of added cards, the preset generator and the `Tools/Preset Builder` window (editor menus)
- [Stats scripts](./stats.md): `Assets/Scripts/Shared/Stats/`: game log (`GameLogFormatter`, `GameLogView`), autoplay simulation (`GameSimulator`, `SimulatedGame`, `SimulatedPath`) and its CSV output (`SimulationCsv`, `TableSimulationRunner`, the Simula button, every preset of the library)
- [Scenes, prefabs and data assets](./scenes.md): the 4 scenes (Menu, then Panchina, Tribuna and Index40 on the table scripts), card, slot, game log, simulation, scene, log toggle and options prefabs (scrollable preset list), the 40 card assets, the `CardDatabase`, the deck presets and their library, project settings the code depends on, the Windows build (menu, texture import rules, settings a build writes)
- [Known issues](./known-issues.md): issues grouped in blocks C–I (A, B, E, G done), one code feature each, with the planned fixing order
