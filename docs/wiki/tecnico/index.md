# Technical

The project's own code and content: scripts in `Assets/Scripts/`, scenes, prefabs, data assets. Unity and plugin behaviour is in their official docs, not here: [Odin Inspector](https://odininspector.com/documentation) (inspector attributes, `OdinEditorWindow`; no official MCP server or `llms.txt` as of 2026-10-19), DOTween, UniTask, TextMeshPro. Back to the [wiki index](../index.md).

- [Shared scripts](./shared.md): `Assets/Scripts/Shared/`: `CardData`, `CardDatabase`, `CardDataInGame`, `CardDisplay3D`, the card generator and `WindowsBuilder` (editor menus), `GameManager`, `SceneLoader` (Menu and Back buttons)
- [Table scripts](./table.md): `Assets/Scripts/Shared/Table/`, shared by the Panchina, Tribuna, Index40 and Bar scenes: `TableState` (logical table state and path rule: duplicates stacked, holes; bench that fills holes face down), `TableDeckManager` (deals a deck preset with a seed, first preset of the library or the normal deck when none, bench or discard beyond 40, game log, reset, events for the HUD, optional end at the 4th king), `OptionsPanel` (preset of the next game from the preset library, animation speed), controller (ignores clicks over the UI), animations, `CardSlot`, `CardSlotContainer`
- [Deck scripts](./deck.md): `Assets/Scripts/Shared/Deck/`: `DeckRules`, `ExcessCards` (panchina, tribuna, index>40), `CardPick` (more removed and duplicated cards at random or the first ones), `ChosenCopies`, `DeckPreset` (chosen removed and duplicated cards plus counts; today custom presets only), `DeckPresetLibrary` (presets shared by scenes, options and simulation), `DeckBuilder` (seeded deal: 40 slots with holes at the end, or index>40 up to 80 slots; no preset = normal deck), `DeckDeal`, the index rule of added cards, the standard and shape preset generators and the `Tools/Preset Builder` card grid (editor menus)
- [Stats scripts](./stats.md): `Assets/Scripts/Shared/Stats/`: game log (`GameLogFormatter`, `GameLogView`), autoplay simulation to the 4th king (`GameSimulator`, `AutoplayStrategy` random or targeted, `SimulatedGame`, `SimulatedPath`), shapes of holes on the grid (`TableShape`, `TableShapes`, `ShapeKind`) and the CSV output on holes and shapes (`SimulationResult`, `SimulationCsv`, `TableSimulationRunner`, the Simula button, every preset of the library)
- [HUD scripts](./hud.md): `Assets/Scripts/Shared/Hud/`, the HUD of the Bar scene (first art style): receipt written card by card (`PathReceipt`, `ReceiptView`), kings face up, tombola card of the holes and complete shapes (`TombolaCard`), road with the omino walking on the path cards (`PathRoadView`), end panel at the 4th king (`EncounterEndView`)
- [Scenes, prefabs and data assets](./scenes.md): the 5 scenes (Menu, then Panchina, Tribuna and Index40 on the table scripts, and Bar: Tribuna with the first art style, palette Nicotina, end at the 4th king), card, slot, game log, simulation, scene, log toggle and options prefabs (scrollable preset list), the 40 card assets, the `CardDatabase`, the deck presets and their library, project settings the code depends on, the Windows build (menu, texture import rules, settings a build writes)
- [Known issues](./known-issues.md): issues grouped in blocks C–J (A, B, E, G done), one code feature each, with the planned fixing order
