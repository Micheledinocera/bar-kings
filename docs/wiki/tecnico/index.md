# Technical

The project's own code and content: scripts in `Assets/Scripts/`, scenes, prefabs, data assets. Unity and plugin behaviour (Odin Inspector, DOTween, UniTask, TextMeshPro) is in their official docs, not here. Back to the [wiki index](../index.md).

- [Shared scripts](./shared.md): `Assets/Scripts/Shared/`: `CardData`, `CardDatabase`, `CardDataInGame`, `CardDisplay3D`, the card generator and `WindowsBuilder` (editor menus), `GameManager`, `SceneLoader` (Menu and Back buttons)
- [Table scripts](./table.md): `Assets/Scripts/Shared/Table/`, shared by the Panchina, Tribuna and Index40 scenes: `TableState` (logical table state and path rule: duplicates stacked, holes; bench that fills holes face down), `TableDeckManager` (deals a deck preset with a seed, bench or discard beyond 40, game log, reset), `OptionsPanel` (preset of the next game, animation speed), controller, animations, `CardSlot`, `CardSlotContainer`
- [Deck scripts](./deck.md): `Assets/Scripts/Shared/Deck/`: `DeckRules`, `ExcessCards` (panchina, tribuna, index>40), `DeckPreset` (the 4 presets: 32, 45, 60, 71 non-king cards), `DeckBuilder` (seeded deal: 40 slots with holes at the end, or index>40 up to 80 slots), `DeckDeal`, the index rule of added cards, and the preset generator (editor menu)
- [Stats scripts](./stats.md): `Assets/Scripts/Shared/Stats/`: game log (`GameLogFormatter`, `GameLogView`), autoplay simulation (`GameSimulator`, `SimulatedGame`, `SimulatedPath`) and its CSV output (`SimulationCsv`, `TableSimulationRunner`, the Simula button)
- [Scenes, prefabs and data assets](./scenes.md): the 4 scenes (Menu, then Panchina, Tribuna and Index40 on the table scripts), card, slot, game log, simulation, scene, log toggle and options prefabs, the 40 card assets, the `CardDatabase` and the deck presets, project settings the code depends on, the Windows build (menu, texture import rules, settings a build writes)
- [Known issues](./known-issues.md): issues grouped in blocks C–I (A, B, E, G done), one code feature each, with the planned fixing order
