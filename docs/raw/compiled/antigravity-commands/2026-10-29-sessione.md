# Sessione — antigravity-commands

Data: 2026-10-29

## Analisi e verifiche effettuate

1. **Funzionamento dei comandi con slash (`/`) in Antigravity**:
   - È stato verificato che Antigravity CLI riconosce i comandi con prefisso slash (`/start`, `/close`) ed esegue direttamente le skill corrispondenti, con piena parità rispetto a Claude Code.
   - Nella TUI interattiva del terminale, digitando `/` compaiono nell'autocompletamento solo i comandi di sistema del client (`/help`, `/skills`, `/model`, `/config`, ecc.), mentre le skill di progetto sono elencate tramite il comando nativo `/skills`.

2. **Parser YAML delle skill**:
   - Individuato un errore nel parsing frontmatter di `report/SKILL.md` dovuto a una descrizione contenente due punti non quotata, risolvibile con sintassi `>-` o racchiudendo la stringa tra virgolette.

3. **Invocazione flessibile delle skill**:
   - Le skill possono essere invocate dall'utente indifferentemente con:
     - Sintassi con slash: `/start <name>`, `/close`, `/ingest`, `/lint-wiki`, `/report <topic>`
     - Prefisso trattino: `-start <name>`, `-close`, ecc.
     - Parola chiave pura: `start <name>`, `close`, ecc.
